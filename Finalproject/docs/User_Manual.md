# MiniOS Nova — User Manual

## 1. Introduction
MiniOS Nova is a command-line operating system simulator built in Python. It provides a simple shell interface to experience basic operating system functionalities like file management, process simulation, and memory tracking.

## 2. System Requirements
- Python 3.x
- Windows Command Prompt (CMD)

## 3. How to Start MiniOS
1. Open Windows Command Prompt (CMD).
2. Navigate to your project directory.
3. Run the following command:
   ```bash
   python main.py
